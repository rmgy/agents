# WARRIORWAYS — THE ASCENT
## Complete Production Script: VR + Viral Build
### "Nobody Looks Down From The Summit And Wishes They'd Quit At The Clouds"
**Exercise:** Pull-Up | **Duration:** 100 seconds | **Format:** 9:16 Vertical
**Series:** ASCENT | **Doodle System:** Reactive — fires on each rep trigger
**VR Depth:** 3-layer parallax (sky/clouds background / athlete / HUD route map)

---

## VISUAL SYSTEM

```
BACKGROUND:    Pre-dawn mountain skyline — dark navy fading to deep blue
               Clouds below, stars above, summit lit by first light
ATHLETE:       Midground — pull-up bar position, rim-lit silver/blue
               Athlete straddles the cloud line — below it on rep 1, above it by rep 12
DOODLE HUD:    Foreground — chalk climbing route, altitude meter, camp marks
DEPTH EFFECT:  3 layers create VR parallax (sky moves UPWARD as athlete pulls —
               creates sensation of genuine vertical ascent)
ACCENT COLOR:  DARK NAVY → SLATE BLUE → SKY BLUE → CLOUD WHITE → SUMMIT GOLD
```

## DOODLE ASSET MAP

```
ROUTE LINE:      Vertical chalk climbing path, left side of frame
                 Dotted marks ascending — base camp at bottom, summit at top
                 Route is grey → fills gold as altitude climbs
ALTITUDE METER:  Right side vertical bar — SEA LEVEL → 1000m → 5000m → SUMMIT
CAMP MARKS:      12 chalk tent/flag tally marks below route
                 Each illuminates as rep completes
WIND LINES:      Chalk wind streaks — start still, intensify with altitude
                 By rep 9: visible crosswind, by rep 12: summit gale effect
CLOUD LAYER:     Doodle cloud mass drawn at frame midpoint — athlete breaks
                 through it at rep 6 (above-the-clouds milestone)
SUMMIT FLAG:     Chalk flag plant animation — drops at rep 12
                 "SUMMITED" in gold, flag waves in wind loop
ALTITUDE TEXT:   Number climbs: SEA LEVEL → 1000m → 3000m → 5000m → "SUMMIT"
```

## VR DEPTH LAYER SYSTEM

```
LAYER 1 — BACKGROUND (sky/atmosphere):
  Visual:  Pre-dawn navy → sky blue → full sunrise gold
  Motion:  Moves UPWARD as athlete pulls (opposite of gravity)
           Background rises to create genuine vertical ascent sensation
  Changes: Progressively lighter — tracks rep count to dawn timing
  VR Feel: By rep 12, viewer feels like they've climbed with the athlete

LAYER 2 — MIDGROUND (athlete):
  Visual:  Sharp, rim-lit silver then gold with sunrise
  Motion:  Natural pull-up movement — vertical axis
  Changes: Lighting warms dramatically (silver → gold) as dawn breaks

LAYER 3 — FOREGROUND (doodle HUD):
  Visual:  Chalk route, altitude meter, camp marks, wind lines
  Motion:  Slightly larger than natural — feels close to viewer
  Changes: Fully reactive to each rep trigger
  VR Feel: Wind lines occasionally sweep ACROSS athlete layer — breaks 2D boundary

PARALLAX TRIGGER MOMENTS:
  Rep 6:   Background pushes UP 10px — cloud layer descends
           Most dramatic VR moment — viewer senses altitude shift
  Rep 9:   Background brightens 15% — dawn beginning
  Rep 12:  Background FLOODS with sunrise gold — total sky reveal

ASCENT vs FORGE vs ROOT PARALLAX:
  FORGE:   Background pushes IN (depth — into the forge)
  ROOT:    Background pushes DOWN (depth — into the earth)
  ASCENT:  Background pushes UP (altitude — into the sky)
  Together: One Series Engine. Three directions. Three dimensions.
```
