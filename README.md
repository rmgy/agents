## 🎨 VISUAL STYLE REFERENCE

### Character Design
- Colored pencil illustration aesthetic
- Realistic head-to-body proportions
- Hand-drawn organic quality
- Expressive, approachable personality
- Curly dark hair, round glasses, warm smile

### Color Palette
```
Primary: Ochre/Gold (#C9941E)     - Character fills, warmth
Accent: Burnt Sienna (#804020)    - Negative/warning states
Growth: Sage Green (#6B8E7F)      - Positive/solution indicators
Support: Warm Grays (#E8E8E8)     - Secondary elements
Base: Black (#000000)             - All outlines (3-4px)
```

### Line Work
- Thick black outlines (3-4px primary, 2-3px secondary)
- Cross-hatching for depth and dimension
- Hand-drawn imperfection suggesting sketch origin
- No gradients—only flat fills with outline separation

## 📞 SUPPORT & TROUBLESHOOTING

### Common Issues & Solutions

**Missing Images in After Effects**
→ Verify import location, check file naming matches prompts, re-link in Project Settings

**Audio Out of Sync**
→ Manually adjust audio layer timing, re-preview section by section

**Slow Playback**
→ Reduce preview resolution to Quarter, close unused panels, disable effect previews

**Rendering Fails**
→ Check for missing footage, resolve all AE warnings, verify codec support

**Colors Look Wrong**
→ Verify project color depth (8-bit), apply Levels correction, check display calibration

See **COMPLETE_WORKFLOW.md** Phase 7 for additional troubleshooting reference.
