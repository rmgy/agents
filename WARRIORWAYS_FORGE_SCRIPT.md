# WARRIORWAYS — THE FORGE
## Complete Production Script: VR + Viral Build
### "Every Blade Starts Cold"
**Exercise:** Push-Up | **Duration:** 100 seconds | **Format:** 9:16 Vertical
**Series:** FORGE | **Doodle System:** Reactive — fires on each rep trigger
**VR Depth:** 3-layer parallax (forge background / athlete / HUD doodles)

---

## VISUAL SYSTEM

```
BACKGROUND:    Dark forge interior — embers, dim orange glow, industrial
ATHLETE:       Midground — push-up position, rim-lit gold/orange
DOODLE HUD:    Foreground — chalk blade, temperature gauge, rep marks
DEPTH EFFECT:  3 layers create VR parallax (background shifts opposite
               to athlete motion — simulates spatial depth)
ACCENT COLOR:  GREY → AMBER → ORANGE → RED → WHITE (transforms with reps)
```

## DOODLE ASSET MAP

```
BLADE:        Vertical chalk sword, left side of frame
              Starts grey → fills with heat color bottom-to-top rep by rep
HEAT METER:   Right side vertical bar — COLD → WARM → HOT → FORGED
REP MARKS:    12 chalk hammer-strike tally marks below blade
              Each illuminates as rep completes
SPARKS:       Doodle sparks burst from blade at reps 6, 9, 12
FORGE STAMP:  "FORGED" badge — hammer + anvil icon — drops at rep 12
TEMPERATURE:  Number climbs: 0° → 200° → 500° → 1000° → "FORGED"
```

## VR DEPTH LAYER SYSTEM

```
LAYER 1 — BACKGROUND (forge environment):
  Visual:  Dark forge interior, embers, amber glow
  Motion:  Moves slightly OPPOSITE to athlete (parallax)
  Changes: Gets more orange/red as reps accumulate
  VR Feel: Creates illusion of physical depth

LAYER 2 — MIDGROUND (athlete):
  Visual:  Sharp, rim-lit, primary focus
  Motion:  Natural push-up movement
  Changes: Lighting intensifies with blade heat (ambient glow on skin)

LAYER 3 — FOREGROUND (doodle HUD):
  Visual:  Chalk blade, heat meter, rep marks, sparks
  Motion:  Slightly larger than natural — feels close to viewer
  Changes: Fully reactive to each rep trigger
  VR Feel: Sparks occasionally cross into athlete layer — breaks 2D boundary

PARALLAX TRIGGER MOMENTS:
  Rep 6:   Background shifts 8px — first depth push
  Rep 9:   Background shifts 12px — deeper
  Rep 12:  Background dims — foreground + athlete only remain
```
