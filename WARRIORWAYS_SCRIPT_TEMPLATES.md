# WARRIORWAYS Script Templates
## Hook-First, Narrative-Driven Approach

---

## MASTER TEMPLATE STRUCTURE
**Duration:** 90 seconds (9:16 vertical)
**Style:** Faceless documentary micro-stories

### Timing Blueprint
```
0–2s   Pattern Interrupt (Hook)
2–5s   Problem Setup (Why This Matters)
5–15s  Visual Demonstration (Movement/Mechanics)
15–35s Insight/Knowledge (Why It Works)
35–55s Proof/Example (Real Impact)
55–75s Transformation (Before → After)
75–90s Challenge/CTA (Open Loop)
```

### Visual Language (All Series)
- NO talking head
- YES: Hands, wrists, shoulders, feet, muscles, shadows
- Close-ups of mechanics
- Slow-motion key moments
- Stopwatch/timer graphics
- Heart-rate animations
- Chalk dust, sweat, progress notebook
- Anatomical overlays (arrows, highlights)
- Minimal kinetic typography
- Clean icons and transitions

# TEMPLATE 1: TECHNIQUE
**Purpose:** Perfect form execution  
**Hook Strategy:** Most people do this wrong / You're probably doing this wrong  
**Audience:** Beginners seeking correct form

```

[VISUAL: Extended rep montage with correct form]

[VOICEOVER: "Better activation. Zero pain. Faster growth. That's the difference between wasting months and building real strength."]
```

## IMPLEMENTATION NOTES

### Open Loop Techniques (Keep Watching)
- "The third mistake is the one everyone makes."
- "Watch what changes after one small adjustment."
- "The next video shows what happens when you combine this with X."
- "Here's what surprises people when they switch permanently..."
- "But here's the thing most people don't know..."
- "Don't copy this step until you understand why."

### Hook Starters (Pattern Interrupts)
- Almost everyone does this wrong
- This tiny mistake costs you months
- Your [body part] isn't weak, it's confused
- The military teaches this differently
- If [problem], watch this
- Most people quit because of this
- This looks easier but it's actually harder
- Can you beat this time?
- Everything you know about this is wrong
- One movement teaches you everything
