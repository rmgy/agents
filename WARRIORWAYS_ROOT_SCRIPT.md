# WARRIORWAYS — THE ROOT
## Complete Production Script: Series Engine #2
### "Nothing Grows Above Ground That Doesn't First Grow Below It"
**Exercise:** Squat | **Duration:** 100 seconds | **Format:** 9:16 Vertical
**Series:** ROOT | **Doodle System:** Reactive — seed → oak fires on each rep
**VR Depth:** 3-layer geological (sky / athlete at ground line / underground roots)
**Badge:** ROOTED | **Accent Color:** Soil brown → green → deep green → gold oak

---

## SERIES CONNECTION

**THE FORGE ended:** *"Come back tomorrow. The forge is waiting."*
**THE ROOT opens:** *"The forge made you hard. Now find out what holds you up."*

These two videos are designed as a pair. THE FORGE = upper body / fire / explosive.
THE ROOT = lower body / earth / patient. Together they complete one warrior.

---

## VISUAL SYSTEM

```
BACKGROUND (sky layer):    Open sky, morning light, soft clouds — above the athlete
ATHLETE (ground layer):    Surface level — squatting on soil/earth, visible ground line
UNDERGROUND (root layer):  Earth cross-section below athlete — roots grow here
DOODLE HUD:                Chalk oak tree — grows simultaneously down AND up
                           Roots visible underground, trunk and canopy above ground
DEPTH EFFECT:              Geological cross-section — 3 distinct visual zones
ACCENT COLOR:              Soil brown (#8B4513) → green (#228B22) →
                           deep green (#006400) → gold oak (#DAA520)
```

## DOODLE ASSET MAP

```
SEED:          Small chalk seed shape — buried below ground line at start
               Cracks open on rep 1 (split animation)

ROOT SYSTEM:   Chalk roots spreading downward and outward below ground line
               Grows deeper and wider with each rep
               By rep 12: roots reach as deep as tree is tall

TRUNK:         Chalk vertical line above ground line — thickens with each rep
               Rep 4: hairline | Rep 8: solid | Rep 12: full girth

BRANCHES:      Chalk branch doodles split from trunk
               Rep 8: two branches | Rep 10: four | Rep 12: full canopy

LEAVES:        Small chalk leaf clusters — appear on branches reps 9–12
               Full canopy by rep 12

GROUND LINE:   Horizontal chalk line dividing above/below
               Consistent throughout — athlete straddles this line

DEPTH METER:   Right side — vertical bar showing root depth
               Label: "DEPTH" — fills downward (opposite of FORGE heat meter)

REP MARKS:     12 small acorn doodles in a row at bottom
               Each acorn fills/illuminates as rep completes

ROOTED BADGE:  Oak tree silhouette inside circle — drops at rep 12
               "ROOTED" in bold green-gold letters beneath it
```

| Element | THE FORGE | THE ROOT |
|---------|-----------|----------|
| Exercise | Push-up (upper body) | Squat (lower body) |
| Direction | Up (lockout/ascent) | Down (depth/descent) |
| Element | Fire | Earth |
| Doodle | Blade heating | Tree growing |
| Meter | Heat (rises up) | Depth (fills down) |
| Sound | Metal / hammer / ring | Soil / wind / crack |
| Tone | Urgent, violent, intense | Patient, inevitable, deep |
| Philosophy | Transformation by pressure | Growth by depth |
| Badge drop | Bounce (explosive) | Settle (grounded) |
| Silence moment | After final hammer | After final earth crack |
| Cross-promo | "Come back tomorrow" | "Go down again tomorrow" |
| VR shift | Parallax push IN | Parallax push DOWN |
| Badge | FORGED | ROOTED |

## VR DEPTH LAYER SYSTEM

```
LAYER 1 — SKY (above athlete):
  Visual:  Open morning sky, soft clouds, golden-hour horizon
  Motion:  Moves very slightly UPWARD as athlete rises (parallax)
  Changes: Brightens as tree grows — tree is making sky more visible

LAYER 2 — GROUND/ATHLETE:
  Visual:  Athlete doing squats — ground line clearly visible
  Motion:  Natural squat movement — descent and ascent
  Changes: Ambient green glow increases as tree grows (root energy reaching up)

LAYER 3 — UNDERGROUND:
  Visual:  Dark soil cross-section — roots growing in this layer
  Motion:  Parallax pushes DOWNWARD with each rep (opposite of FORGE)
  Changes: Root system fills this layer progressively rep by rep
  VR Feel: Root tendrils occasionally cross INTO athlete's layer
           (breaks 2D boundary — same technique as FORGE sparks)

PARALLAX TRIGGER MOMENTS:
  Rep 4:  Sky brightens (tree visible above ground)
  Rep 6:  Underground shifts DOWN 10px — depth reveal
  Rep 9:  Underground fills frame width — maximum root spread
  Rep 12: Above ground dims — underground ILLUMINATES
          The invisible becomes the visible. That's the ending.
```
