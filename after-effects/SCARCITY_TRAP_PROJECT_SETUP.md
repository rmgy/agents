## SCENES 4-10: LAYER STRUCTURE TEMPLATE

Each remaining scene follows this general layer structure:

```
Layer [Top]:    Text Elements (fade in/out on cue)
Layer [+1]:     Motion Effects (pulse, rotation, entrance/exit)
Layer [+1]:     Data Visualizations (animated graphs/meters)
Layer [+1]:     Objects & Icons (layered, timed appearances)
Layer [+1]:     Character Expressions/Details (eye movement, mouth)
Layer [+1]:     Character Main Body (primary animated layer)
Layer [Base]:   Background (locked, no animation)
```

### General Animation Principles (Applies to All Scenes)

1. **Character Entrance:** Fade in during first 5-10 frames of scene
2. **Micro-expressions:** Blink every 30-40 frames
3. **Hand Gestures:** Natural movement, 3-5 frame transitions
4. **Object Stagger:** Offset object appearances by 10-30 frames
5. **Text Timing:** Fade in 10 frames, hold, fade out 10 frames
6. **Data Viz Animation:** Gradual reveal of data (0.5-1.0 second duration)
7. **Motion Effects:** Entrance 20 frames, hold varied duration, exit 15-20 frames

## ESSENTIAL PLUGINS & EFFECTS

### Built-in After Effects Effects to Use

**For Characters:**
- Opacity Animations (fade in/out)
- Transform: Position (movement, gestures)
- Transform: Rotation (head turns, hand rotation)
- Transform: Scale (emphasis effects)

**For Text:**
- Opacity Animations
- Text Animator: Offset (staggered letter entrance)
- Stroke effect for emphasis

**For Motion Effects:**
- Rotation (spirals, spinning objects)
- Glow effect (optional, on icons)
- Turbulent Displace (optional, for waviness)

**For Data Visualization:**
- Stroke animation (reveal line charts)
- Opacity (bar chart segment appearance)
- Trim Paths (reveal pie slices)

**For Overall:**
- Color Balance (warmth adjustment)
- Levels (contrast enhancement)
- Fast Box Blur (optional softening)

### Third-Party Recommendations (Optional)
- **Tapered Stroke:** More organic hand-drawn line appearance
- **Curve Bounce:** Natural easing for character movements
- **DUIK:** Advanced character rigging (for hand gestures)

## TROUBLESHOOTING QUICK REFERENCE

| Issue | Solution |
|-------|----------|
| Images appearing pixelated | Verify source is 1920x1080, check scale settings |
| Audio out of sync | Check audio track timing, resync in Master comp |
| Slow preview playback | Lower preview resolution to quarter, reduce layer complexity |
| Transparency issues | Verify alpha channel in image import settings |
| Colors appear washed out | Check color profile, apply levels adjustment |
| Text looks blurry | Ensure text rasterization is off or convert to shape |
| Composition won't render | Check for missing footage, resolve all warnings |
